# Ukrainian cues. One Python regex per line, matched against normalized lowercase text
# (code blocks and quoted lines removed, latin look-alikes inside cyrillic words mapped,
# dot/dash obfuscation inside cyrillic words collapsed). Lines starting with # are comments.
#
# Sections:
#   [profanity]  swearing and insults                        -> 0.5, or 1.0 when [directed] also matches
#   [praise]     positive swearing / positive context        -> silences profanity
#   [directed]   the message addresses the agent             -> upgrades profanity to 1.0
#   [blame]      complaint aimed at the agent's work         -> 1.0, no swearing needed
#   [failure]    something does not work                     -> 1.0 only together with [repeat]
#   [repeat]     it keeps happening                          -> see [failure]
#   [negative]   mild negativity                             -> 0.5
#   [ack]        explicit go-ahead; clears the streak and a level-3 stop (anchored at start)
